# Build: Internationalized Page

Build a single HTML page that demonstrates proper language and internationalization attributes.

**Requirements checklist**

- Proper `lang` attribute on `<html>` using BCP 47 format
- At least one element with a different `lang` attribute (e.g., a foreign word or phrase)
- Correct use of `dir` attribute if demonstrating RTL content
- At least 8 non-blank lines total
- Proper document structure with doctype, html, head, body

When you're happy with it, submit using the editor, or upload the `.html`
file if you built it locally.
