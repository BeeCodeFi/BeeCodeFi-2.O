# 🏗️ Comments & HTML Entities/Special Characters

## 💬 HTML Comments {#html-comments}

```html
<!-- This is a comment, not shown to the user -->
```

- Not rendered by the browser, but visible in page source — never put sensitive info in comments.
- Cannot be nested.
- Useful for notes to your future self, temporarily disabling code, or marking sections (`<!-- Header -->`, `<!-- End Header -->`).

## ❓ Why Entities Exist {#why-entities-exist}

Certain characters are **<span style="color: #ef4444;">reserved</span>** in HTML because the parser uses them for markup itself — most importantly `<` and `>` (tag delimiters) and `&` (starts an entity/character reference). If you type these literally as content, the browser may misinterpret them as markup. <span style="color: #3b82f6;">Character references</span> let you safely represent them, along with characters not on a standard keyboard (©, emoji-adjacent symbols, non-breaking spaces).

## 🔣 The Anatomy of a Character Reference {#character-reference-anatomy}

Format: `<span style="color: #14b8a6; font-family: monospace;">&amp;name;</span>` (named) or `<span style="color: #14b8a6; font-family: monospace;">&amp;#number;</span>` / `<span style="color: #14b8a6; font-family: monospace;">&amp;#xHEX;</span>` (numeric), always starting with `&` and ending with `;`.

| Character | Entity Name | Numeric |
|---|---|---|
| `<` | `&lt;` | `&#60;` |
| `>` | `&gt;` | `&#62;` |
| `&` | `&amp;` | `&#38;` |
| `"` | `&quot;` | `&#34;` |
| `'` | `&apos;` | `&#39;` |
| (non-breaking space) | `&nbsp;` | `&#160;` |
| © | `&copy;` | `&#169;` |

## ⚠️ The Three "Always Escape These" Characters {#always-escape}

`<`, `>`, and `&` are the ones that *must* be escaped when they appear as literal content (not markup), since they have structural meaning to the parser.

## 🔠 Case Sensitivity {#case-sensitivity}

Named references are <span style="color: #f59e0b; font-weight: bold;">case-sensitive</span> — `&Amp;` is not the same as `&amp;` and may not resolve correctly.

## ❌ Common Misconceptions {#common-misconceptions}

- Forgetting entities are **<span style="color: #f59e0b;">case-sensitive</span>**.
- Using multiple literal spaces expecting them to render — browsers collapse whitespace to a single space; `&nbsp;` is needed to force extra space (more in Topic 13).
- Assuming comments are hidden from users entirely — they're invisible on the rendered page but fully visible in "View Source."

**Summary in 5 lines:**

- **<span style="color: #10b981;">Comments</span>** (`<!-- -->`) aren't rendered but are visible in source — don't hide secrets there.
- **<span style="color: #ef4444;">Reserved characters</span>** (`<`, `>`, `&`) must be escaped via character references.
- References come in **<span style="color: #3b82f6;">named</span>** (`&lt;`) or **<span style="color: #3b82f6;">numeric</span>** (`&#60;` / `&#x3C;`) form.
- Entity names are **<span style="color: #f59e0b;">case-sensitive</span>**.
- `<span style="color: #14b8a6; font-family: monospace;">&amp;nbsp;</span>` forces a non-breaking space where normal whitespace would collapse.
