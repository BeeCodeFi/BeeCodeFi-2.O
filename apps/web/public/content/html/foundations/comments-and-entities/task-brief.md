# Build: an HTML entity cheatsheet

Build a single HTML page that works as a quick-reference "cheatsheet" for
HTML entities. It should render **at least 6 different entities**, each with
a visible text label describing what it is, and it must contain at least one
HTML comment in the source.

**Requirements checklist**

- `<html>`, `<head>`, `<title>`, `<body>` (the boilerplate)
- One heading (`<h1>`) introducing the cheatsheet
- At least 6 entities rendered on the page, each with a label, for example:
  - `Copyright symbol: &copy;`
  - `Ampersand: &amp;`
  - `Less than: &lt;`
  - `Greater than: &gt;`
  - `Non-breaking space: A&nbsp;&nbsp;&nbsp;B`
  - `Numeric reference: &#169;`
- At least one HTML comment (`<!-- ... -->`) anywhere in the source
- At least 10 non-blank lines total

When you're happy with it, submit using the editor, or upload the `.html`
file if you built it locally.
