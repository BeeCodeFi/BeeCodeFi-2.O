# Build: the standard HTML boilerplate

Reproduce the standard HTML document structure **from memory** — no
copy-pasting from the lesson. This is the skeleton every page you ever
write will start from.

**Requirements checklist**

- `<!DOCTYPE html>` as the very first line
- `<html>` with a `lang` attribute (e.g. `lang="en"`)
- `<head>` containing at least:
  - `<meta charset="UTF-8">`
  - `<title>` with some text inside it
- `<body>` — it can be empty or contain a single placeholder comment
- At least 8 non-blank lines total
- No visible text, images, or scripts placed inside `<head>`

When you're happy with it, submit using the editor, or upload the `.html`
file if you built it locally.
