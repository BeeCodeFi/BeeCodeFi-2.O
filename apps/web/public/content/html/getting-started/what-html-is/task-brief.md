# Build: Hello Web

Build a single, simple HTML page that introduces you to the web — literally.

**Requirements checklist**

- `<html>`, `<head>`, `<title>` (the page's name), and `<body>` (the boilerplate)
- One heading (`<h1>`) with a greeting or your name
- One paragraph (`<p>`) that introduces yourself in a sentence or two
- At least 8 non-blank lines total
- No links or images yet — those come in later lessons

When you're happy with it, submit using the editor, or upload the `.html`
file if you built it locally.
