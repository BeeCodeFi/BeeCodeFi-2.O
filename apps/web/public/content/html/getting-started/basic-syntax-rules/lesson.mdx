# Basic Syntax Rules (elements, tags, attributes, nesting, void elements)

## Elements vs. Tags {#elements-vs-tags}

An **element** = opening tag + content + closing tag (e.g., `<p>Hello</p>`). A **tag** is just the `<p>` or `</p>` part. People often use "tag" loosely to mean "element" — understand both terms.

## Attributes {#attributes}

Provide additional information about an element, written inside the opening tag as `name="value"`:

```html
<a href="https://example.com" target="_blank">Link</a>
```

- Double or single quotes are both valid; be consistent (convention: double quotes).
- Some attributes are **boolean** — their mere presence means "true" (e.g., `disabled`, `required`, `checked`); no value needed: `<input disabled>`.

## Nesting {#nesting}

Elements can contain other elements, but must nest properly — like parentheses:

```html
<!-- Correct -->
<p>This is <strong>important</strong> text.</p>

<!-- Incorrect (crossed tags) -->
<p>This is <strong>important</p></strong>
```

## Void (Self-Closing / Empty) Elements {#void-elements}

Some elements have no content and no closing tag, e.g. `<img>`, `<br>`, `<hr>`, `<input>`, `<meta>`, `<link>`. In HTML syntax you can write `<br>` or `<br />` — both are valid; the trailing slash is optional and purely stylistic in HTML (it matters in strict XHTML).

## Block vs. Inline (preview) {#block-vs-inline}

Some elements naturally start on a new line and take full width (block, e.g. `<p>`, `<div>`), others flow inline with surrounding text (e.g. `<span>`, `<a>`). This is really a CSS `display` concept, but default browser stylesheets set it per element.

## Common Misconceptions {#common-misconceptions}

- Thinking every element needs a closing tag — void elements don't.
- Improper nesting ("crossing" tags) — browsers often "fix" this silently, but it's invalid and unpredictable.
- Confusing "tag" and "element" in technical contexts (matters less day-to-day, matters in interviews/specs).

**Summary in 5 lines:**

- Element = opening tag + content + closing tag; tag = just the markers.
- Attributes add info via `name="value"` in the opening tag; some are boolean (presence = true).
- Nesting must not cross — like balanced parentheses.
- Void elements (`<img>`, `<br>`, `<input>`, etc.) have no closing tag.
- Block vs inline default behavior comes from the browser's default stylesheet.
