# Build: 8 elements, done right

Build a single HTML page that uses **at least 8 different elements**,
including at least one element with an attribute and one image with real
`alt` text.

**Requirements checklist**

- `<html>`, `<head>`, `<title>`, `<body>` (the boilerplate)
- One heading (`<h1>`)
- One paragraph (`<p>`)
- One image with an `alt` attribute (`<img alt="...">`)
- One link with an `href` attribute (`<a href="...">`)
- At least 15 non-blank lines total
- No `<table>` — save tables for their own lesson later

When you're happy with it, submit using the editor, or upload the `.html`
file if you built it locally.
