# HTML Boilerplate & Meta Tags

## What "Boilerplate" Means {#what-boilerplate-means}

The standard skeleton every HTML page starts with — the minimum setup needed before you write actual content:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page Title</title>
  <meta name="description" content="Brief page description">
</head>
<body>

</body>
</html>
```

## `<meta charset="UTF-8">` {#meta-charset}

Declares the character encoding. UTF-8 covers virtually all characters/emoji from all languages and is the modern default recommendation. Should be declared as early as possible in `<head>` (ideally the very first line) since browsers may re-parse the page if it's declared too late.

## The Viewport Meta Tag {#viewport-meta}

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

Critical for responsive design — without it, mobile browsers render the page at a fake "desktop width" (usually 980px) and scale it down, making text tiny. `width=device-width` matches the CSS viewport width to the device; `initial-scale=1.0` sets the initial zoom level.

## `<title>` {#title-element}

Sets the browser tab text, bookmark name, and default search-result title. Every page needs exactly one — required for valid HTML.

## `<meta name="description">` {#meta-description}

Not required for validity, but used by search engines for the snippet shown in results (SEO relevance covered fully in Topic 42).

## Common Misconceptions {#common-misconceptions}

- Thinking `charset` doesn't matter if the text is "just English" — non-UTF-8 pages can break on curly quotes, em dashes, emoji, or any non-ASCII input later.
- Skipping the viewport tag and wondering why the site looks "zoomed out" on mobile.
- Confusing `<title>` (browser tab) with an `<h1>` (visible on-page heading) — they serve different purposes and should usually both exist.

**Summary in 5 lines:**

- Boilerplate = the standard minimum `<head>`/`<body>` skeleton for every page.
- `<meta charset="UTF-8">` should be declared first, to avoid encoding issues.
- The viewport meta tag is essential for correct mobile rendering.
- `<title>` is required and distinct from a visible `<h1>`.
- `<meta name="description">` isn't required but affects SEO snippets.
