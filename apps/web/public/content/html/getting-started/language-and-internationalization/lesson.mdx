# Language & Internationalization Basics

## The `lang` Attribute {#lang-attribute}

Declares the primary human language of an element's content (usually set once on `<html>`):

```html
<html lang="en">
```

Uses **BCP 47 language tags** — e.g. `en` (English), `en-US` (US English), `fr` (French), `hi` (Hindi), `ja` (Japanese). Format: primary language subtag, optionally followed by a region subtag.

## Why `lang` Matters (not cosmetic) {#why-lang-matters}

- **Accessibility**: screen readers use it to select correct pronunciation rules.
- **SEO/Search**: search engines use it to serve language-appropriate results.
- **Browser features**: enables correct spell-check dictionaries, translation prompts, and font selection for some scripts.
- Can be set on a *specific element* too, if part of a page is in a different language:

```html
<p>The French word for "hello" is <span lang="fr">bonjour</span>.</p>
```

## The `dir` Attribute {#dir-attribute}

Declares text direction:
- `dir="ltr"` — left-to-right (default; English, Hindi, most languages)
- `dir="rtl"` — right-to-left (Arabic, Hebrew)
- `dir="auto"` — browser infers direction from content

```html
<html lang="ar" dir="rtl">
```

## Interaction with Layout {#interaction-with-layout}

RTL affects more than text flow — margins, padding, and flex/grid direction can flip too (this becomes very relevant once you learn CSS logical properties, outside HTML's scope but good to know exists).

## Common Misconceptions {#common-misconceptions}

- Thinking `lang` is purely decorative/optional — it has real accessibility and SEO impact.
- Forgetting `dir="rtl"` when working with Arabic/Hebrew content, leading to garbled visual layout even though the HTML is "correct."
- Using full language *names* ("English") instead of the correct BCP 47 code ("en").

**Summary in 5 lines:**

- `lang` declares content language using BCP 47 tags (e.g. `en`, `hi`, `fr`).
- Set on `<html>` for the whole page, or on specific elements for exceptions.
- `lang` affects screen reader pronunciation, SEO, and browser language features.
- `dir` declares text direction: `ltr`, `rtl`, or `auto`.
- RTL languages (Arabic, Hebrew) need `dir="rtl"` for correct layout.
